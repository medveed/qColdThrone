# qThroneMobile 2.6

- В настройках TUN появился переключатель «Блокировать QUIC», по умолчанию включён. QUIC (UDP 443) теперь отклоняется только для трафика, который идёт через прокси: браузер сразу переходит на TCP и не зависает. Сайты и приложения, которые идут напрямую, снова могут пользоваться QUIC. Если выключить переключатель, QUIC не блокируется совсем.

CSQTT остаётся на исходном 2.5.0 Legacy. APK устанавливается поверх предыдущей версии с сохранением профилей и настроек.
