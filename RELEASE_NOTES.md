# qThroneMobile 2.4.5

- Обновление подписки больше не затирает вручную изменённые хеши qWDTT, CSQTT и WDTT Plus. Выбранное число воркеров сохраняется и уменьшается только тогда, когда новый лимит хешей его не допускает. Также сохраняются режим (WG/RAW), источник хешей и настройки транспорта: SRTP, TURN, отпечаток, client id, капча, токен VK.
- Тайм-аут запроса подписки по умолчанию — 10 секунд.
- Для каждой подписки можно задать свой период автообновления. 0 — как в общих настройках.
- Правило сортировки серверов перенесено в окно «Редактировать». Настройки подписки собраны в один раздел, самые нужные пункты — сверху.
- Карточка загрузки файлов маршрутизации теперь появляется при каждом обновлении подписки, а не через раз. Её можно скрыть нажатием. Ошибка загрузки geo-файла больше не отменяет импорт маршрутизации.
- После разблокировки экрана или выхода из спящего режима приложение проверяет связь через туннель и переподключается само, если связи нет.
- Значок qThrone в строке состояния больше не пропадает при включённом VPN.
- SSTP: открыт доступ к локальной сети за сервером, как в OpenConnect. Сеть, к которой подключён телефон, остаётся доступной напрямую.
- Кнопка подключения на главном экране стала компактнее.

CSQTT остаётся на исходном 2.5.0 Legacy. APK устанавливается поверх предыдущей версии с сохранением профилей и настроек.
