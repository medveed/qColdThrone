# qThroneMobile 2.4.8

- Браузер больше не зависает на QUIC: UDP 443 через туннель отклоняется, и браузер сразу переходит на обычное HTTPS-соединение. Особенно заметно на сервисах Google.
- Если IPv6 в туннеле выключен, DNS не отдаёт IPv6-адреса, и браузер не тратит время на попытки подключиться по IPv6.
- Оптимистичный кэш DNS включён по умолчанию: после простоя первая страница открывается без ожидания DNS-запроса.
- При включённом Fake-IP таблица фейковых адресов сохраняется между переподключениями.
- После разблокировки экрана мёртвый туннель обнаруживается и перезапускается быстрее.
- Пинг-тест: первому запросу к серверу даётся на 5 секунд больше, поэтому медленные, но рабочие серверы больше не помечаются недоступными.

CSQTT остаётся на исходном 2.5.0 Legacy. APK устанавливается поверх предыдущей версии с сохранением профилей и настроек.
