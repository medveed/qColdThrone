# qThroneMobile 2.6.1

- Новый пинг больше не ждёт, пока закроется тестовое ядро прошлого, поэтому после частых нажатий профили не крутятся подолгу.
- После сна больше не нужно переподключаться. Если экран был выключен дольше 30 секунд, при включении старые соединения сбрасываются, и трафик и проверка текущего соединения сразу идут по новым.
- При открытии раздела «Маршрутизация» больше не появляется уведомление «Перезапустите прокси-сервис», если ничего не менялось.
- Профили, добавленные по ссылке или из буфера, сразу появляются в списке серверов. Раньше приходилось свернуть и развернуть список.

CSQTT остаётся на исходном 2.5.0 Legacy. APK устанавливается поверх предыдущей версии с сохранением профилей и настроек.
